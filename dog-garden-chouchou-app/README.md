## 特に注意すべき点

- **`service_role` キーをアプリに置かない。** `NEXT_PUBLIC_` 変数はブラウザに配信されるため、置いた時点で RLS を無視できる鍵が公開される
- **RLS を無効にしない。** データが見えるかどうかは `app_users` 名簿と RLS が決めている。画面側のチェックは理由表示のためだけ
- **物理削除しない。** 法令の5年保存があるため `deleted_at` による論理削除のみ
- **血統を推測で紐付けない。** 現行台帳の血統表記は犬舎にいない犬も含むため、原文を `breeder_note` に保持している
