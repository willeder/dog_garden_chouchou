# SEO 設計と運用ガイド

最終更新: 2026年8月16日

---

## 0. 最初に：ゴールの整理と、できること・できないこと

ご依頼は「みんぶり（みんなのブリーダー）で調べた時に絶対でてきてほしい」でした。
この言葉には**性質のまったく違う3つ**が含まれているため、最初に分けます。

| # | ゴール | 自社サイトのSEOで動かせるか | 難易度 |
| --- | --- | --- | --- |
| A | Googleで**犬舎名**を検索したとき（指名検索）、みんなのブリーダーの掲載ページより公式サイトが上に出る | **動かせる** | 低（1〜3ヶ月） |
| B | Googleで**地域＋犬種**（例:「福岡 ブリーダー マルチーズ」）で検索したとき上位に出る | **動かせる** | 高（6ヶ月〜） |
| C | **みんなのブリーダーのサイト内**の検索結果・おすすめ順で上位に出る | **動かせない** | ― |

### なぜ C は動かせないのか

みんなのブリーダーのサイト内順位は、同社が持つ独自のロジック（掲載プラン、成約実績、
レビュー数・評価、更新頻度、返信スピードなど）で決まります。
これは**先方のプラットフォーム内の話**であり、公式サイトを何度改善してもGoogle経由では影響しません。

Cを上げたい場合は、みんなのブリーダーの担当者に直接
「掲載順位の決まり方」「上位表示プランの有無」を問い合わせるのが唯一の正攻法です。
**サイト制作の予算をここに投じても効果はゼロ**なので、切り分けておくべきです。

今回は A と B の両方を狙う方針（ご選択）で設計しています。

### 現状の把握（2026年8月16日時点で確認）

現在「ドッグガーデンシュシュ 福岡 筑紫野市 ブリーダー」で検索すると、
[みんなのブリーダーの犬舎ページ](https://www.min-breeder.com/breeder_e913201.html)がヒットします。
一方で公式サイトはまだ存在しない（未公開）ため、**指名検索の受け皿が他社ドメインだけの状態**です。

つまり今は「A のゴールに向けて、公式サイトという受け皿を作った」段階です。
公開してインデックスされれば、指名検索は比較的短期で取れる見込みです。

## 1. 実装済みの技術的SEO

すべて実装・ビルド検証済みです。

### 1-1. canonical（重複URL対策）— 不具合を1件修正しました

**修正前の状態:** 全ページが `<link rel="canonical" href="（トップのURL）">` を出力していました。
これは「このサイトの全ページはトップページの複製である」とGoogleに宣言している状態で、
放置すると**下層ページがインデックスから消えます**。

**修正後:** ページごとに正しい自己参照canonicalを出力します。

```
/         → https://（ドメイン）/
/about    → https://（ドメイン）/about
/puppies  → https://（ドメイン）/puppies
```

実装は `app/_config/metadata.ts` の `generateMetadata(title, description, path)`。
全ページに `path` を渡すよう修正済みです。

### 1-2. h1 の欠落を修正しました

**修正前:** 全13ページに `<h1>` が1つもありませんでした（すべて `<h2>` 始まり）。
Googleはページの主題を判断する手がかりを失います。

**修正後:** 全ページに `<h1>` を1つずつ設置しました。

| ページ | h1 |
| --- | --- |
| `/` | ドッグガーデンシュシュ｜福岡県筑紫野市のブリーダー |
| `/about` | ドッグガーデンシュシュについて |
| `/puppies` | 仔犬紹介 |
| `/puppies/[id]` | （犬種）（性別） 例: マルチーズ（男の子） |
| `/adoption` | 里親のお迎えについて |
| 他 | 各ページのセクション見出し |

TOPのh1は「犬舎名（指名検索）＋地域＋業種（地域検索）」を1行に収めた形にしています。
キービジュアル上にキャッチコピーより小さく配置しており、デザインは崩していません。

### 1-3. 犬舎名の表記ゆれを修正しました

`/about` とTOPの見出しが「**ドック**ガーデンシュシュについて」（濁点なし）になっていました。
正式名称は「ドッ**グ**ガーデンシュシュ」です。

指名検索は表記の一致が効くため、**ブランド名の誤記は指名検索で直接損をします**。
3箇所すべて修正しました。Figmaの原稿がこの表記だった場合はご指摘ください。

### 1-4. 構造化データ（JSON-LD）

Googleが現在サポートしているタイプだけを実装しています
（[構造化データギャラリー](https://developers.google.com/search/docs/appearance/structured-data/search-gallery)で2026年8月時点の対応状況を確認）。

| タイプ | 出力場所 | 狙い |
| --- | --- | --- |
| `LocalBusiness` + `PetStore` | 全ページ | 犬舎の実体（名称・住所・代表者・動物取扱業登録番号）をGoogleに伝える。**ゴールAの中核** |
| `WebSite` | 全ページ | 検索結果のサイト名表示 |
| `BreadcrumbList` | 全下層ページ | 検索結果のURL表示が階層形式になりクリック率が上がる |
| `Product` + `Offer` | 仔犬詳細 | 価格・在庫状況（募集中／商談中／成約済み）を伝える |

**`sameAs` に みんなのブリーダーの犬舎ページURL を登録しました。**
これは「みんなのブリーダーに載っているこの犬舎＝この公式サイト」という同一性の宣言で、
ゴールAで**みんなのブリーダーのページに集まっている評価を公式サイトに引き寄せる**役割を持ちます。
Instagram・TikTokも同様に登録済みです。

#### あえて実装しなかったもの：FAQPage

FAQページがあるので通常なら `FAQPage` を入れますが、**今回は入れていません。**

> Googleは **2026年5月7日に FAQ リッチリザルトの提供を終了**し、
> 6月15日には該当ドキュメント自体を削除しました。現在 `FAQPage` は検索結果に一切影響しません。
> 参照: [Google FAQPage after May 7, 2026: official guidance](https://fennecseo.app/blog/google-faq-structured-data-update/) /
> [FAQ Rich Results Deprecated: Google's May 2026 Change](https://www.getpassionfruit.com/blog/what-changed-with-google-drops-faq-rich-results-and-what-to-do-now)

効果がないものを入れると保守コストだけが残るため見送りました。
**FAQの本文そのものはユーザーに有用なので、ページ表示は維持しています。**

### 1-5. その他の基礎

| 項目 | 状態 |
| --- | --- |
| `robots.txt` | 自動生成（`app/robots.ts`）。sitemapのURLを明記 |

## 2. 公開後に必ずやること（優先度順）

技術的な土台は整いました。**ここから先はサイト側だけでは完結せず、運用が必要です。**

### ステップ1：独自ドメインを取得する【最優先】

`.vercel.app` のサブドメインのままだと、指名検索でも公式サイトとして扱われにくくなります。
`dog-garden-chouchou.com` のように**犬舎名がそのまま入ったドメイン**を推奨します。

取得後は Vercel の環境変数 `NEXT_PUBLIC_SITE_URL` を書き換えて再デプロイするだけで、
canonical・sitemap・OGP・構造化データのURLがすべて自動で追従します。

### ステップ2：Google Search Console に登録する

1. [Search Console](https://search.google.com/search-console) でドメインプロパティを追加
2. DNSのTXTレコードで所有権を確認
3. 「サイトマップ」に `sitemap.xml` を送信
4. 「URL検査」でトップページを検査 →「インデックス登録をリクエスト」

これをやらないと、Googleがサイトを見つけるまで数週間かかることがあります。

### ステップ3：Googleビジネスプロフィールを作る【ゴールAとBの両方に効く】

指名検索したときに右側に出る事業者情報パネルです。地図検索の受け皿にもなります。

**ただし注意点があります。**

Googleの規定では、拠点の住所を非公開にできるのは
「**客先に出向いてサービスや商品を提供し、ビジネス拠点の住所では接客しないビジネス**」に限られます
（参照: [非店舗型ビジネスとハイブリッド型ビジネスのサービス提供地域を管理する](https://support.google.com/business/answer/9157481?hl=ja)）。

**見学を犬舎（ご自宅）で受け入れている以上、この条件には当てはまりません。**
つまり住所を非公開にしたままの登録は規定違反となり、審査で止まる・停止されるリスクがあります。

自宅住所の公開に抵抗がある場合の選択肢は次の3つです。ご判断ください。

| 案 | 内容 | 備考 |
| --- | --- | --- |
| a | 住所を公開して登録 | 地図検索に最も強い。ただし住所がGoogleマップに出る |
| b | ビジネスプロフィールを作らない | 現在の住所は既にみんなのブリーダーに掲載されているため、実質的な差は小さいという見方もできます |
| c | 見学専用の別拠点を用意して登録 | 現実的でない場合が多い |

> なお、犬舎の住所は**第一種動物取扱業の表示義務**があり、すでに公式サイトの
> 「犬舎概要」「動物取扱業登録」欄で公開しています。この点も踏まえてご検討ください。

### ステップ4：外部からの言及（サイテーション）を揃える

Googleは「同じ名称・住所・電話番号があちこちで一致しているか」で事業者の実在性を判断します。
以下を**まったく同じ表記**で統一してください。

- 犬舎名: `ドッグガーデンシュシュ`（英字は `Dog Garden ChouChou`）
- 住所: `福岡県筑紫野市美しが丘南5-17-1`

統一すべき掲載先:

- [ ] みんなのブリーダーの犬舎ページ（**公式サイトURLの掲載欄があれば必ず入れる**）
- [ ] Instagram プロフィールのリンク欄 → 公式サイトURL
- [ ] TikTok プロフィールのリンク欄 → 公式サイトURL
- [ ] 公式LINEのプロフィール／リッチメニュー → 公式サイトURL
- [ ] Googleビジネスプロフィール（作る場合）

> みんなのブリーダー側の犬舎ページに公式サイトURLを載せられるかは、
> 掲載プランによって異なる可能性があります。担当者にご確認ください。
> **ここが載せられるなら、ゴールAへの効果が最も大きい1手です。**

### ステップ5：素材とドラフトの確定

未確定のまま公開すると、内容の薄いページとして評価されます。

- [ ] ブリーダー様のお写真（現在グレーの丸）
- [ ] 16:9のメイン写真×3、Instagram実投稿画像×3
- [ ] 生体保証・利用規約・プライバシーポリシー・見学の注意点の文面確定
- [ ] キャッチコピーの確定
- [ ] 郵便番号（構造化データの `postalCode` に反映されます）

## 3. ゴールB（地域＋犬種検索）のための中長期施策

ここは**コンテンツの継続投入以外に近道がありません。**
「福岡 ブリーダー マルチーズ」のような語は、みんなのブリーダー・ブリーダーナビ・
愛犬オンラインといった大手ポータルが上位を占めており、
個人犬舎の公式サイトが割り込むには6ヶ月〜1年の積み上げが要ります。

### 効く順に

1. **仔犬情報を止めずに更新する**
   microCMSに新しい仔犬を登録し続けること自体が更新頻度のシグナルになります。
   1頭ごとに詳細ページ（＝インデックス対象URL）が増えます。

2. **お客様の声を増やす**
   「福岡市 T様宅」のように**地名入りの見出し**にすると、地域の実績として拾われます。
   現在ranと同じ形式（地名＋様宅＋犬種＋名前）になっています。この形式を守ってください。

3. **犬種ごとの解説を書く**
   `breed_explanation` フィールドが使えます。
   「マルチーズの性格と飼い方」のような内容を各仔犬ページに入れると、
   犬種名での流入が増えます。**ただし全頭コピペは逆効果**なので、犬種ごとに1本ずつ用意してください。

4. **ブログ／お知らせ機能の追加（未実装）**
   本気でゴールBを取るなら、これが最も効きます。
   microCMSに `blog` APIを追加し、月2〜4本のペースで
   「筑紫野市で子犬をお迎えするまでの流れ」「福岡で見学に来られる方へ」といった
   地域名を含む記事を出す運用です。**実装をご希望であればご相談ください。**

## 4. 効果の測り方と、判断の目安

### 見る場所

- **Search Console →「検索パフォーマンス」**：どの語で何回表示され、何回クリックされたか
- **Search Console →「ページのインデックス登録」**：登録されていないページが無いか
- **Google Analytics 4**（`NEXT_PUBLIC_GA_ID` 設定で有効化）：LINE誘導ボタンまで到達した数

### 目安

| 時期 | 期待できる状態 |
| --- | --- |
| 公開1〜2週間 | 全ページがインデックスされる |
| 公開1〜3ヶ月 | **「ドッグガーデンシュシュ」で1位**（ゴールA達成） |
| 公開3〜6ヶ月 | 「筑紫野市 ブリーダー」など競合の少ない語で上位 |
| 公開6ヶ月〜 | 「福岡 ブリーダー ◯◯（犬種）」で1ページ目を狙える段階 |

3ヶ月経っても指名検索で公式サイトが1位にならない場合は、
ドメイン・インデックス・サイテーションのどこかに問題があります。ご連絡ください。

## 5. やってはいけないこと

- **キーワードの詰め込み**：本文に「福岡 ブリーダー」を不自然に繰り返す。順位が下がります
- **他サイトからの文章コピー**：みんなのブリーダーの紹介文をそのまま転載しない
  （現在の犬舎紹介文は、みんなのブリーダー掲載文をベースに書き直した別の文章にしています）
- **有料の被リンク購入**：Googleのガイドライン違反で、手動対策を受けると回復に数ヶ月かかります
- **同じ内容のページを量産する**：犬種ページを中身ほぼ同じで5つ作る、など
